## Task 1: Data Cleaning

**Objective:**  
To clean and preprocess the given dataset in order to make it suitable for analysis.

**Work Done:**  
- Identified and handled missing values  
- Cleaned and normalized numerical columns  
- Ensured data consistency  
- Exported the cleaned dataset for further analysis  

**Output File:**  
- `cleaned_data.csv`

---

## Task 2: Data Analysis

**Objective:**  
To perform basic exploratory data analysis on the cleaned dataset.

**Work Done:**  
- Calculated statistical measures such as mean, median, standard deviation, minimum, and maximum  
- Generated a summarized analysis report  
- Stored the analysis results in a CSV file  

**Output File:**  
- `analysis_summary.csv`
