# RD-INFRO-TECHNOLOGY

This repository contains data-related tasks completed as part of the RD INFRO TECHNOLOGY assignment workflow.

---

## Task 1: Data Cleaning

**Folder:** `Task-1-Data-Cleaning`

### Files
- `data.csv`  
  Original raw dataset

- `cleaned_data.csv`  
  Dataset after handling missing values, removing duplicates, and normalizing numeric features

- `data_cleaning.ipynb`  
  Jupyter Notebook documenting the complete data cleaning process

### Operations Performed
- Dataset loading and inspection
- Missing value handling
- Duplicate removal
- Min–Max normalization
- Export of cleaned dataset

---

## Task 2: Data Analysis & Visualization

**Folder:** `Task-2-Data-Analysis`

### Files
- `analysis_data.csv`  
  Cleaned dataset used for analysis

- `data_analysis.ipynb`  
  Notebook containing exploratory data analysis and visualizations

- `analysis_summary.csv`  
  Statistical summary generated using `pandas.describe()`

### Analysis Performed
- Dataset structure and distribution analysis
- Descriptive statistics
- Numeric feature visualization (histograms, boxplots)
- Correlation analysis
